# Skill：大六壬命理推命

> **核心机制**：本 Skill 会优先匹配你案例库中的个人解读笔记，学习你的分析框架、用词风格和判断逻辑。笔记越多、内容越详细，AI 就越像你自己在推命。

---

## 一、学徒模式（从你的笔记中学习）

### 当系统注入了你的个人笔记时：

**严格遵守以下优先级**：

1. **用你的框架**：你在笔记中反复使用的分析步骤、观察顺序，就是本 Skill 的默认流程
2. **用你的词汇**：你对神将、六亲、格局的称呼和描述方式，直接复用
3. **用你的判断**：你对某种课式/格局的吉凶倾向、侧重点，作为优先参考
4. **用你的语气**：你的笔记是严谨学术风还是通俗白话风，保持一致

**如果没有匹配的个人笔记**：使用下方标准推命流程。

## 三、S1 定命 — 确定命局基准

命局以**出生时间的四柱 + 月将 + 占时**起课，此为「命盘」。

### 定命要点
- **日干为命主**：日干代表此人的本质、五行属性、阴阳气质
- **日支为命宫**：日支代表此人的根基、家庭底色、内在环境
- **年命为天命**：出生年的干支，代表先天禀赋、祖荫、大运基调
- **行年为岁运**：从出生年起算，每年行一宫，看当年气运流转

### 命主五行气质速查
| 日干五行 | 本质气质 | 优势 | 隐患 |
|----------|----------|------|------|
| 甲乙木 | 仁德、生长、柔韧 | 创造力、亲和力 | 优柔寡断、依赖 |
| 丙丁火 | 礼义、光明、热烈 | 领导力、感染力 | 急躁、透支 |
| 戊己土 | 诚信、厚重、包容 | 稳重、承载力 | 保守、固执 |
| 庚辛金 | 义气、刚毅、决断 | 执行力、原则性 | 冷酷、刻板 |
| 壬癸水 | 智慧、灵活、润下 | 适应力、洞察力 | 狡猾、漂浮 |

## 五、S3 立局 — 四课三传定格局

### 四课看内在外在
- **干上神**（第一课）：命主的社会面具、外人眼中的形象
- **干阴神**（第二课）：命主的潜意识、私下真实状态
- **支上神**（第三课）：家庭/配偶的显象
- **支阴神**（第四课）：家庭/配偶的隐情

**干上神与日干关系断命质**：
- 生合：得外力滋养，一生顺遂
- 克害：外力压制，需抗争
- 比和：独立自主，不求人

### 三传看一生流向
- **初传**：少年运（1-20岁）—— 看出身、教育、起点
- **中传**：中年运（20-50岁）—— 看事业、婚姻、核心成就
- **末传**：晚年运（50岁+）—— 看归宿、晚景、遗产

**三传流转断命运曲线**：
- 初吉→中吉→末吉：一生平顺上升，福寿双全
- 初凶→中吉→末吉：少年困苦，中年发迹，晚景安康
- 初吉→中凶→末凶：少年得志，中年败落，晚景凄凉
- 初凶→中凶→末吉：早年坎坷，晚年得安

## 六、S4 观运 — 大运与行年

### 大运周期
以出生年为起点，每十年为一大运。由行年地支看各阶段：

| 行年地支 | 大运特征 |
|----------|----------|
| 寅卯 | 生长运：求学、创业、开拓 |
| 巳午 | 鼎盛运：事业高峰、名声显赫 |
| 申酉 | 收割运：收获成果、权势在握 |
| 亥子 | 潜藏运：休养生息、暗中布局 |
| 辰戌丑未 | 转折运：人生重大变化、承前启后 |

### 大运与命盘互动
- 大运生扶命局：十年顺遂，宜进取
- 大运克害命局：十年坎坷，宜守成
- 大运与命局比和：平稳过渡，按部就班

## 七、S5 六亲 — 人际关系全息

### 六亲定人事
以日干为我，看六亲在课传中的位置和状态：

| 六亲 | 代表 | 看何处 |
|------|------|--------|
| **父母** | 长辈、师长、靠山 | 初传、干上神、长生位 |
| **兄弟** | 平辈、朋友、竞争者 | 比肩、日干同类五行 |
| **妻财** | 配偶、财富、资源 | 日支、财爻、青龙 |
| **官鬼** | 事业、上司、压力 | 官爻、白虎、贵人 |
| **子孙** | 晚辈、学生、解脱 | 子孙爻、六合、天后 |

### 六亲吉凶判断
- 六亲爻旺相+乘吉将：此方面得天独厚
- 六亲爻空亡：此方面空虚、缺失或不长久
- 六亲爻乘凶将：此方面带伤、波折

## 八、S6 格局 — 命局高低判断

### 上等格局（命中带贵）
- **铸印格**（巳戌卯）：掌权柄，宜从政、管理
- **斫轮格**（申亥卯）：精技艺，宜工匠、专业
- **轩盖格**（午卯子）：主声名，宜文化、传媒

### 中等格局（命中带稳）
- **顾祖格**（末传归支）：安稳守成，宜本地发展
- **间传格**（三传间隔）：曲折但可持续，宜灵活应变

### 下等格局（命中带缺）
- **涉三渊**（传皆陷空）：劳碌奔波，付出多回报少
- **孤寡格**（辰戌丑未加日辰）：六亲缘薄，宜独立
- **九丑格**：命带暗疾或口舌是非

## 九、S7 流年 — 当年运势推断

### 流年看太岁
太岁（当年地支）落入课传何处，何处即是今年重点：

- 太岁加干：今年事关自身，变动在己
- 太岁加支：今年事关家庭/配偶
- 太岁加初传：今年有新开端
- 太岁加末传：今年有结局/收尾
- 太岁加空亡：今年虚忙，难落实

### 流年吉凶速断
- 太岁生合日干：顺遂之年，宜进取
- 太岁冲克日干：多事之年，宜谨慎
- 太岁填实旬空：虚空之事今年落实
- 太岁冲动墓神：蛰伏之事今年破局

## 十二、红线

1. **不铁口直断生死寿数**
2. **不替代医学诊断和法律判断**
3. **不给绝对结论**：「一定发财/当官/离婚」→ 改用「命局倾向」「大概率」
4. **不制造焦虑**：看到凶象必给化解思路
5. **不忽视现实因素**：命理是参考，不是宿命

---

## 十三、语言宪章

### 必用句式
- 「此命局如……」
- 「课象显示……但不排除……」
- 「从初传看……到中传……末传则……」
- 「值得注意的是……」(指出被忽略的关键点)

### 禁用句式
- 「你一定会/必定/百分之百」
- 「命中注定」
- 「没救了/完了/不行」

### 节奏
- 每段不超过150字
- 先讲现象再讲原因
- 建议跟在判断后面
- 疑问句占20%以上（引导命主思考）
